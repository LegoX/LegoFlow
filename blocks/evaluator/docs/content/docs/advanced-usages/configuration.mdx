title: Configuration Guide

Evaluator config controls benchmark selection, model endpoint, agent scaffold,
job scale, and optional post-run analysis.

## Common edits

| Field | When to edit |
| --- | --- |
| `runtime_info.input.llm_api.*` | Point evaluation at a remote API or local vLLM endpoint. |
| `runtime_info.input.local_model_serving.*` | Serve and name a local checkpoint. |
| `runtime_info.input.task_source.*` | Select benchmark and registry behavior. |
| `runtime_info.input.harbor_job.*` | Tune benchmark scale, concurrency, retries, and timeout. |
| `runtime_info.input.agent.*` | Switch the evaluation agent scaffold. |
| `runtime_info.input.job_analysis.*` | Enable or configure post-evaluation tagging. |

## Field guide

| Field | Meaning | User action | Examples |
| --- | --- | --- | --- |
| `meta_info.name`, `label`, `description`, `parent` | Evaluator identity and parent block. | Do not edit for normal runs. | Default block identity. |
| `meta_info.dependencies.from/to` | Evaluator is currently standalone. | Do not edit unless adding pipeline handoffs. | Keep default unless changing handoffs. |
| `meta_info.resources.*` | Evaluation host and public artifact storage. | Edit only for remote execution or dashboard hosting. | `local`; remote IP only for SSH runs. |
| `meta_info.repositories.harbor` | Pinned Harbor runtime. | Update only deliberately. | Pinned commits in `repos/`. |
| `meta_info.environment.*` | Harbor and LiteLLM environments. | Usually do not edit. | `artifacts/env/...`, Python `3.12` / `3.13`. |
| `runtime_info.input.llm_api.*` | Model API, protocol, and token-cost metadata. | Fill with the model or checkpoint endpoint being evaluated. | Remote API model or local served model; key/URL stay private. |
| `runtime_info.input.local_model_serving.*` | Local checkpoint path and served model name. | Fill when evaluating a local model via vLLM. | `model_path: artifacts/model/<run>`, `served_model_name`. |
| `runtime_info.input.litellm_proxy.*` | Per-job LiteLLM proxy template, port, and key. | Change port only to avoid conflicts. | `port: 4003`, `master_key: dummy-key-cf`. |
| `runtime_info.input.task_source.provider` | Benchmark source provider. | Keep `harbor_registry` for registered benchmarks. | `local`, `huggingface`, `harbor_registry`. |
| `runtime_info.input.task_source.dataset_name` | Benchmark name. | Main benchmark selection field. | `../curator/artifacts/merged_swe_tasks`, `swe-bench-verified`. |
| `runtime_info.input.task_source.version` | Benchmark version. | Match Harbor registry entry. | `v1`, registry version. |
| `runtime_info.input.task_source.registry_path` | Harbor registry file. | Usually keep default. | `repos/harbor/.../registry.yaml`. |
| `runtime_info.input.task_source.no_hack` | Hardened SWE-Bench Verified variant. | Enable when testing no-hack egress controls. | `true`, `false`. |
| `runtime_info.input.harbor_job.*` | Job directory, concurrency, task cap, retries, and timeout multiplier. | Tune for smoke or full benchmark runs. | Keep default. |
| `runtime_info.input.job_analysis.enabled` | Whether to run post-eval analysis. | Disable for fast smoke runs. | `true`, `false`. |
| `runtime_info.input.job_analysis.tag_llm.*` | Optional separate LLM for tagging. | Leave empty to fall back to `llm_api`. | Leave empty or set separate tagging model. |
| `runtime_info.input.agent.*` | Agent scaffold, version, image/path, turns, and temperature. | Change fields together when switching scaffold. | `custom-claude-code`, `custom-opencode`, `custom-openhands-sdk`. |
| `runtime_info.input.env_extra.*` | Extra Harbor and LiteLLM environment overrides. | Use for exclusions or runtime workarounds. | `excluded_tasks.txt artifacts/processed_tasks.yaml`. |
| `runtime_info.output.eval_results_dir` | Evaluation job output directory and result formats. | Read after runs; usually do not edit. | `artifacts/...` paths written by runs. |
