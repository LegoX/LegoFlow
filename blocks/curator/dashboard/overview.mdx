# Curator — Overview

**Block**: `curator` | **Type**: data | **Parent**: `legoflow`

## What This Block Does

Converts GitHub PRs into verified SWE-Bench tasks across 8 programming languages
(Python, JavaScript, TypeScript, Go, C, C++, Java, Rust). The separate
collector writes PR ID pools. `swegen create` reads those pools, filters and
evaluates PRs through an OpenAI-compatible LLM, generates task skeletons via
the Claude Code SDK, and validates each candidate with Harbor NOP/Oracle runs
before appending it to `verifiable_tasks.txt`.

## Quick Start

```bash
# 1. Install
python -m venv artifacts/envs/swegen-env && source artifacts/envs/swegen-env/bin/activate
pip install -e repos/swegen/
# 2. Set GITHUB_TOKENS / GITHUB_TOKEN or a local token file; fill config.yaml -> llm_api
# 3. Validate
bash scripts/dryrun.sh
# 4. Collect PRs and wait for the background PID to exit
bash scripts/collect_all_bg.sh
# 5. Launch detached generation workers (pick the provider mode)
bash scripts/start_with_anthropic_api.sh    # cc_provider_mode: native
bash scripts/start_with_openai_api.sh       # temporary proxy stops when launcher returns
```

## Key Files

| File | Purpose |
