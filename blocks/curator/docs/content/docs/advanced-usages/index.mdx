This section collects Curator recipes for inspecting and improving finished
task datasets. Start here when the basic generation path already works and you
want to understand task quality in more detail.

## Recipes

- [Quality Rubrics](/docs/advanced-usages/quality-rubrics) explains how Curator
  scores difficulty and where those scores are stored.
- [Task Tagging](/docs/advanced-usages/task-tagging) explains the four-tag task
  schema and how tags support filtering, balancing, and dashboard analysis.

For the shortest runnable workflow, return to [Getting Started](/docs/getting-started).
