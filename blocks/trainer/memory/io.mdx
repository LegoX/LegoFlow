# Inputs & Outputs

## Current Inputs (`config.yaml` → `runtime_info.input`)

`config.yaml` is the source of truth for the one-shot dataset source, model,
training hyperparameters, output directory, WandB mode, and uv environment path.
The current profile selects one exact JSON through `hf_lf` + `hf_file_name`,
uses `Qwen/Qwen3.5-35B-A3B-Base` with the `qwen3_5` template, and trains with
DeepSpeed ZeRO-3 on eight GPUs. Run `bash scripts/dryrun.sh` to validate those
values against the current machine before training.

## Current Outputs (`config.yaml` → `runtime_info.output`)

| Output | Value |
|---|---|
| checkpoint_path | Updated in `config.yaml.runtime_info.output` after a successful run |
| final_loss | Read from `<output_dir>/train_results.json` when available |
| total_steps | Read from `<output_dir>/trainer_state.json` when available |
| train_runtime | Read from `<output_dir>/train_results.json` when available |
| training_log | `artifacts/logs/<run_name>_<timestamp>.log` |
| training_curves | WandB run id when available |

See `config.yaml` for full paths.
