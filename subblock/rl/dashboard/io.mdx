# Inputs / Outputs

## Inputs

See `inputs.yaml` for all runtime configuration (model path, infra, data paths, credentials).

Key fields:
- `model.model_path`: base model checkpoint
- `infrastructure.*`: node count, GPU count, vLLM TP size, ports
- `training.*`: batch size, parallel tasks, max turns, sequence lengths
- `data.*`: parquet paths and task directories
- `experiment.*`: project name, experiment name, trials base dir
- `credentials.wandb_api_key`: WandB API key

## Outputs

See `outputs.yaml` for runtime output values written after each run.

Key fields:
- `checkpoint_path`: latest trained actor model checkpoint
- `val_resolve_rate`: SWE-bench-Verified resolve rate (%) for best checkpoint
- `training_curves`: WandB run URL with reward, loss, token counts, timing metrics
- `trajectory_log_dir`: JSONL logs of all agent API traffic from rollouts
