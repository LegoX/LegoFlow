# SWE-gen — Overview

**Block**: `swegen` | **Type**: data | **Parent**: `swe_lego_live`

## What This Block Does

Converts GitHub PRs into verified SWE-Bench tasks across 8 programming languages
(Python, JavaScript, TypeScript, Go, C, C++, Java, Rust).

Runs as an adaptive agent: monitors per-language success rates every 30 minutes and
tunes `timeout`, `cc_timeout`, and `n_concurrent` automatically.

## Quick Start

```bash
# 1. Install
python -m venv swegen-env && source swegen-env/bin/activate
pip install -e repos/swegen/
# 2. Set env vars (or place tokens in ~/gh_token.txt)
# 3. Validate
bash scripts/dryrun.sh
# 4. Run
bash scripts/start.sh
```
