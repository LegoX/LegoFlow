# SWE-gen — Status

See `config.yaml -> status` for live phase, current job, next steps, and blockers.

## Per-Language Status

Per-language run state (verified counts, last batch result, current run, etc.)
lives in `artifacts/index.yaml`. The static per-language *configuration* is in
`config.yaml -> runtime_info.input.languages.<lang>`.

## Logs

- `artifacts/logs/swegen-create/cc_<lang>_March.txt` — per-language create logs
- `artifacts/index.yaml` — appended per-run summary (started_at, status, archive)
- `artifacts/archives/run_NNN/` — full per-run snapshots
