# Status

## Source Of Truth

Read `config.yaml → status` for the current `phase`, `progress`, `current_job`,
blockers, and operator next steps. Read `artifacts/index.yaml` for archived run
entries.

Time convention: `last_updated` and per-run timestamps are recorded in UTC.
Existing job directory names may include the local launch timestamp (`UTC+8`) so
they continue to match the actual artifact path.

## Next Steps

Use `config.yaml → status.next_steps` for the live checklist. During an active
job, monitor `artifacts/jobs/<job>` and update `status` after inspection.

## Experiment Runs

Use `artifacts/index.yaml` for archived run records.
