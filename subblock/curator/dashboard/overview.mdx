# Curator — Overview

**Block**: `curator` | **Type**: data | **Parent**: `swe_lego_live`

## What This Block Does

Converts GitHub PRs into verified SWE-Bench tasks across 8 programming languages
(Python, JavaScript, TypeScript, Go, C, C++, Java, Rust). The `swegen create`
pipeline collects PRs, filters and evaluates them through an OpenAI-compatible
LLM, generates a task skeleton via the Claude Code SDK, and validates each
candidate task with Harbor NOP/Oracle runs before appending it to
`verifiable_tasks.txt`.

## Quick Start

```bash
# 1. Install
python -m venv swegen-env && source swegen-env/bin/activate
pip install -e repos/swegen/
# 2. Set env vars (or place tokens in ~/gh_token.txt) and fill config.yaml -> llm_api
# 3. Validate
bash scripts/dryrun.sh
# 4. Run (pick the mode that matches llm_api.cc_provider_mode)
bash scripts/start_with_anthropic_api.sh    # cc_provider_mode: native
bash scripts/start_with_openai_api.sh       # cc_provider_mode: openai_proxy
```

## Key Files

| File | Purpose |
|------|---------|
| `config.yaml` | Per-language `params` (timeout/cc_timeout/n_concurrent) + `llm_api` |
| `artifacts/merged_swe_tasks/` | Optional merged verified SWE tasks (flat directory) |
| `artifacts/swe_tasks/` | Per-language task directories |
| `artifacts/collected_prs/` | PR ID lists per language |
| `artifacts/logs/swegen-create/` | Per-language create logs |
