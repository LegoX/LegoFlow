# Curator — Status

`config.yaml -> status` is descriptive configuration text; the generation
scripts do not update it.

## Per-Language Status

Read live per-language progress from the create logs,
`artifacts/swe_tasks/<lang>-cc/.swegen-create-batch/`, and
`verifiable_tasks.txt`. The static per-language configuration is in
`config.yaml -> runtime_info.input.languages.<lang>`.

## Logs

- `artifacts/logs/swegen-create/cc_<lang>_March.txt` — per-language create logs
- `artifacts/index.yaml` — appended launcher summary; `completed` means the
  background launcher returned, not that detached workers finished
- `artifacts/archives/run_NNN/` — launcher metadata plus config/script snapshots
