# Curator — Inputs & Outputs

See `config.yaml` for the full dependency schema.

## Runtime Inputs (`config.yaml`)

| Field | Description |
|-------|-------------|
| `runtime_info.input.pr_collection.*` | Collector languages, scale, output path, token limit, and filters |
| `runtime_info.input.llm_api.*` | OpenAI-compatible and Claude Code provider settings |
| `runtime_info.input.languages.<lang>.params` | Per-language timeout, cc_timeout, and n_concurrent |
| *(GitHub tokens)* | Never stored in config.yaml; provided via `GITHUB_TOKENS` / `GITHUB_TOKEN` env vars or ignored token files |

`config.yaml` does not hold live metrics. Read worker progress from create logs,
`.swegen-create-batch/`, and `verifiable_tasks.txt`.

Environment variables required before running:

| Variable | Purpose |
|----------|---------|
| `GITHUB_TOKENS` / `GITHUB_TOKEN` | GitHub tokens merged by the collector with its local token file |
| `COLLECT_GITHUB_TOKEN_FILE` | Optional override for the collector's default `repos/swegen/gh_token.txt` |
| `OPENAI_API_KEY` | LLM API key |
| `OPENAI_API_BASE_URL` | OpenAI-compatible endpoint |
| `OPENAI_MODEL` | Model for PR evaluation |
| `ANTHROPIC_BASE_URL` | Claude Code endpoint or local compatibility proxy |
| `ANTHROPIC_MODEL` | Model for Claude Code SDK |

## Runtime Outputs (`config.yaml`)

`runtime_info.output.swe_tasks_dir.path` points to per-language task pools under
`artifacts/swe_tasks/`. `runtime_info.output.merged_tasks_dir.path` points to the
optional flattened export under `artifacts/merged_swe_tasks/`. Each task contains:
- `instruction.md` — problem description
- `environment/Dockerfile` — build environment
- `environment/bug.patch` — bug-introducing patch
- `solution/fix.patch` — ground truth fix
- `tests/test.sh` — verification script
