# SFT Training

SFT training pipeline for SWE-bench coding models. It accepts Harbor trajectories,
a Hugging Face dataset or exact Hub file, or a local ShareGPT file, then trains via
LLaMA-Factory + DeepSpeed ZeRO-3.

## Current Stage

One-shot run inputs and the latest published outputs live in `config.yaml`; live
run state is recorded in `artifacts/index.yaml` and training files under
`artifacts/model/<run>/`. The real-time view is the dashboard webui
(`dashboard/start_dashboard.sh`, serves :8091). Use `bash scripts/dryrun.sh`
before launching a run to verify the configured source data, model path,
output directory, and GPU count.

## Pipeline

```text
harbor_job ─▶ convert trajectory → IM → score/filter → LF JSON ─┐
hf_lf + hf_file_name ─▶ download one exact Hub file ────────────┤
hf_lf (no file name) ─▶ register Hub dataset config/split ──────┤
local_lf ─▶ register an existing local LF JSON ─────────────────┘
                                                               │
                                                               ▼
                                              dataset_info.json registration
                                                               │
                                                               ▼
                                  python -m llamafactory.cli train <generated YAML>
                                                               │
                                                               ▼
                                                  artifacts/model/<run>/
```

## Environment

Run `bash scripts/install_env.sh` from `subblock/trainer` to recreate the uv environment
configured at `meta_info.environment.sft_uv`. The script installs
PyTorch 2.10.0 CUDA 12.8 wheels, editable `swe_data_process[llm]` and the patched
LLaMA-Factory plus its metrics/DeepSpeed/Liger requirements, source-built
`flash-attn`, Qwen3.5's `flash-linear-attention` and `tilelang` dependencies,
and `wandb`.
