# SFT Training

SFT training pipeline for SWE-bench coding models. Converts Harbor job trajectories
into LLaMA-Factory ShareGPT format and trains via LLaMA-Factory + DeepSpeed ZeRO-3.

## Current Stage

The active run state lives in `config.yaml` and the training artifacts under
`artifacts/model/<run>/`; the real-time view is the dashboard webui
(`dashboard/start_dashboard.sh`, serves :8091). Use `bash scripts/dryrun.sh`
before launching a run to verify the configured source data, model path,
output directory, and GPU count.

## Pipeline

```
Harbor job trajectories (job_dir, per-scaffold)
    └─▶  python -m swe_data_process.<subpackage>.convert_*_to_im
              └─▶  Intermediate "IM" format (PangUML v2 JSONL, score in meta_info.unique_info)
                        └─▶  rule_score.py (auto-invoked) + optional llm_score.py
                                  └─▶  LLaMA-Factory "LF" format (ShareGPT JSON)
                                            └─▶  artifacts/data/lf_data/<dataset>.json
                                                      └─▶  python -m llamafactory.cli train <generated_config.yaml>
                                                                └─▶  artifacts/model/<run>/
```

## Supported Converter Matrix

## Environment

Run `bash scripts/install_env.sh` from `subblock/trainer` to recreate the uv environment
configured at `meta_info.environment.sft_uv`. The script installs
`swe_data_process[llm]`, PyTorch 2.8.0 CUDA 12.8 wheels,
`LLaMA-Factory[torch,metrics,deepspeed,liger-kernel]`, the pinned flash-attn
2.8.3 wheel under `artifacts/wheels/`, and `wandb`.
