title: Motivation
description: Why we built trajgen
---

trajgen turns verified SWE tasks into agent trajectories and ready-to-train SFT data.

It is the trajectory-generation stage of the [SWE-Lego-Live](https://github.com/SWE-Lego/SWE-Lego-Live) self-evolving LLM pipeline: it sits between task curation (`swegen`) and model training (`sft`, `rl`). Given a set of verified software-engineering tasks, trajgen rolls a coding agent out across them inside reproducible containers, captures every step of each rollout, and converts the successful ones into supervised fine-tuning datasets.

We built trajgen because generating *training-grade* agent data at scale is more than just "run an agent in a loop". You need reproducible environments, a model endpoint that speaks both OpenAI and Anthropic protocols, careful bookkeeping so no task is ever rolled out twice, and a conversion step that reshapes raw logs into the exact format your trainer expects. trajgen wraps all of that around a pinned [Harbor](https://github.com/SWE-Lego/harbor) checkout so a single config drives the whole run.

trajgen provides:

- **Manifest-gated task consumption** — only tasks marked verified in swegen's `verifiable_tasks.txt` are ever run, and a consumption ledger guarantees each task is rolled out exactly once
- **A per-job LiteLLM proxy** in front of your model API, exposing both OpenAI- and Anthropic-compatible endpoints to whichever agent scaffold you choose
- **Containerized rollouts at scale** through Harbor, with configurable concurrency, retries, and per-task timeout multipliers
- **Pluggable agent scaffolds** — Claude Code, OpenCode, OpenHands SDK, and Terminus-2 are all pre-integrated
- **Automatic SFT data conversion** from raw trajectories to LLaMA-Factory format, with rule-based and LLM-based trajectory quality scoring
- **A live progress dashboard** you can preview locally or publish to Cloudflare Pages
