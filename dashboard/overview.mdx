## New-User Quickstart

### Prerequisites

- SSH access to `192.168.35.240` as `root` (the remote CPU node where swegen and trajgen run)
- Docker available on the remote node
- Python 3.10+ locally
- A GitHub token with `repo` read scope
- An OpenAI-compatible LLM API endpoint (used for PR evaluation and trajectory generation)

### Step 1 — Fill in config

Edit `subblock/swegen/config.yaml` and `subblock/trajgen/config.yaml`. In each file, fill the `runtime_info.input` section:

**swegen** needs:
- `runtime_info.input.github_tokens` — GitHub API token(s), comma-separated
- `runtime_info.input.llm_api.api_key` — LLM API key
- `runtime_info.input.llm_api.api_base_url` — OpenAI-compatible endpoint
- `runtime_info.input.llm_api.pr_model` and `task_model` — model name (e.g. `openai/gpt-4o`)

**trajgen** needs:
- `runtime_info.input.llm_api.api_key`, `api_base_url`, `model` — same LLM endpoint

### Step 2 — Validate

```bash
bash scripts/dryrun.sh
```

Checks local config files, required fields, and SSH reachability. Add `--full` to also run each subblock's own dryrun on the remote node.

### Step 3 — Start

```bash
bash scripts/start.sh
```

Syncs code to the remote node and launches swegen and trajgen in named tmux sessions (`swegen-py` and `trajgen`). Use `--swegen-only` or `--trajgen-only` to start one at a time. Use `--dry-run` to preview the commands without executing.

### Step 4 — Monitor

```bash
ssh root@192.168.35.240
tmux ls
tmux attach -t swegen-py    # watch swegen task generation
tmux attach -t trajgen      # watch trajgen trajectory generation
```

swegen logs: `subblock/swegen/artifacts/logs/swegen-create/cc_py_March.txt`  
trajgen logs: `subblock/trajgen/artifacts/jobs/<job>/` (one directory per Harbor job)

### Step 5 — Check progress

The agent updates `subblock/trajgen/artifacts/consumption_ledger.yaml` with per-task status (pending / done / failed / skipped). swegen verified task counts are in `subblock/swegen/artifacts/swe_tasks/{lang}-cc/verifiable_tasks.txt`.

| **rl** | Online RL from trajectory rewards | Planned |
