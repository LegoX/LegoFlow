# Inputs & Outputs

## Input Schema

Defined in `meta-info.yaml`. These are the values this block requires before it can run.

| Name | Description | Source | Required |
|---|---|---|---|
| github_token | GitHub API token for SWE-gen repo access | external | yes |
| anthropic_api_key | Anthropic API key for Claude Code agent | external | yes |
| openai_api_key | OpenAI API key for PR evaluation | external | no |

## Current Input Values

Stored in `inputs.yaml`. Fill these before starting a run.

```yaml
github_token: ""
anthropic_api_key: ""
openai_api_key: ""
```

## Current Output Values

Written by the agent to `outputs.yaml` after a run completes.

```yaml
version: null
produced_at: null
outputs: {}
```
