# SWE-Lego-Live: a self-evolving agent to develop coding agents

A block-structured system for automating the LLM development pipeline — data curation, SFT/RL training, and evaluation — through a self-evolving agent. Users interact verbally with the agent while it provides human-readable feedback on progress.

See `docs/main.md` for current state, or `BLOCK_DEFINITION.md` for the block system design.
