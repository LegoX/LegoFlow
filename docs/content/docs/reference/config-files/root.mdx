---
title: Root Config
---

The root `config.yaml` describes the LegoFlow block tree. For a normal local
run, users do not need to fill any required root fields. The only user-facing
choices are optional basic settings: Cloudflare for dashboard publishing and
Docker for authenticated pulls, mirrors, or a non-default daemon.

## Common edits

| Field | When to edit |
| --- | --- |
| `runtime_info.input.cloudflare.*` | Optional. Fill only if you want root or block dashboards published through Cloudflare. |
| `runtime_info.input.docker.*` | Optional. Fill only when Docker pulls need a registry, login, mirror, or non-default daemon. |
| `meta_info.*` | Do not fill for normal use; this is root orchestration metadata. |

## Field guide

| Field | Meaning | User action |
| --- | --- | --- |
| `meta_info.name` | Machine name of the root block. | Do not edit. |
| `meta_info.label` | Human-facing project label. | Edit only for branding. |
| `meta_info.description` | One-line purpose of the root block. | Edit only when project scope changes. |
| `meta_info.parent` | Root has no parent, so this is `null`. | Do not edit. |
| `meta_info.blocks` | Child blocks and their role summaries. | Read to understand pipeline stages. |
| `meta_info.dependencies.from` | Root has no upstream dependency. | Do not edit. |
| `meta_info.dependencies.to` | Root does not publish a direct child handoff. | Do not edit. |
| `meta_info.resources.ip` | Where root orchestration runs. | Keep `local` for normal use. |
| `meta_info.resources.directory` | Remote working directory if root runs remotely. | Usually leave `null`. |
| `runtime_info.input.cloudflare.account_id` | Cloudflare account for dashboard publishing. | Optional. Leave empty unless publishing. |
| `runtime_info.input.cloudflare.api_token` | Cloudflare token for publishing. | Optional. Never commit a real token. |
| `runtime_info.input.cloudflare.pages_project_prefix` | Prefix for dashboard Pages projects. | Optional branding/namespace value. |
| `runtime_info.input.docker.registry` | Docker registry override. | Leave empty for Docker default. |
| `runtime_info.input.docker.username` | Docker registry username. | Optional; prefer env/secret handling. |
| `runtime_info.input.docker.password` | Docker registry password or token. | Optional. Never commit a real secret. |
| `runtime_info.input.docker.mirror` | Docker mirror endpoint. | Optional, useful for slow pulls. |
| `runtime_info.input.docker.host` | Docker daemon host. | Leave empty for default local daemon. |
| `runtime_info.output` | Root-level produced values. | Currently empty. |
