title: Evaluator Config
---

Evaluator config controls benchmark selection, model endpoint, agent scaffold,
job scale, and optional post-run analysis.

## Common edits

| Field | When to edit |
| --- | --- |
| `runtime_info.input.llm_api.*` | Point evaluation at a remote API or local vLLM endpoint. |
| `runtime_info.input.local_model_serving.*` | Serve and name a local checkpoint. |
| `runtime_info.input.task_source.*` | Select benchmark and registry behavior. |
| `runtime_info.input.harbor_job.*` | Tune benchmark scale, concurrency, retries, and timeout. |
| `runtime_info.input.agent.*` | Switch the evaluation agent scaffold. |
| `runtime_info.input.job_analysis.*` | Enable or configure post-evaluation tagging. |

## Field guide

| Field | Meaning | User action |
| --- | --- | --- |
| `meta_info.name`, `label`, `description`, `parent` | Evaluator identity and parent block. | Do not edit for normal runs. |
| `meta_info.dependencies.from/to` | Evaluator is currently standalone. | Do not edit unless adding pipeline handoffs. |
| `meta_info.resources.*` | Evaluation host and public artifact storage. | Edit only for remote execution or dashboard hosting. |
| `meta_info.repositories.harbor` | Pinned Harbor runtime. | Update only deliberately. |
| `meta_info.environment.*` | Harbor and LiteLLM environments. | Usually do not edit. |
| `runtime_info.input.llm_api.*` | Model API, protocol, and token-cost metadata. | Fill with the model or checkpoint endpoint being evaluated. |
| `runtime_info.input.local_model_serving.*` | Local checkpoint path and served model name. | Fill when evaluating a local model via vLLM. |
| `runtime_info.input.litellm_proxy.*` | Per-job LiteLLM proxy template, port, and key. | Change port only to avoid conflicts. |
| `runtime_info.input.task_source.provider` | Benchmark source provider. | Keep `harbor_registry` for registered benchmarks. |
| `runtime_info.input.task_source.dataset_name` | Benchmark name. | Main benchmark selection field. |
| `runtime_info.input.task_source.version` | Benchmark version. | Match Harbor registry entry. |
| `runtime_info.input.task_source.registry_path` | Harbor registry file. | Usually keep default. |
| `runtime_info.input.task_source.no_hack` | Hardened SWE-Bench Verified variant. | Enable when testing no-hack egress controls. |
| `runtime_info.input.harbor_job.*` | Job directory, concurrency, task cap, retries, and timeout multiplier. | Tune for smoke or full benchmark runs. |
| `runtime_info.input.job_analysis.enabled` | Whether to run post-eval analysis. | Disable for fast smoke runs. |
| `runtime_info.input.job_analysis.tag_llm.*` | Optional separate LLM for tagging. | Leave empty to fall back to `llm_api`. |
| `runtime_info.input.agent.*` | Agent scaffold, version, image/path, turns, and temperature. | Change fields together when switching scaffold. |
| `runtime_info.input.env_extra.*` | Extra Harbor and LiteLLM environment overrides. | Use for exclusions or runtime workarounds. |
| `runtime_info.output.eval_results_dir` | Evaluation job output directory and result formats. | Read after runs; usually do not edit. |
