title: Curator Config
---

Curator config controls task discovery and task generation. This is where users
choose repository collection scope, PR filters, LLM endpoints, and per-language
generation limits.

## Common edits

| Field | When to edit |
| --- | --- |
| `runtime_info.input.pr_collection.*` | Change collection scale, languages, output directory, or repository/PR filters. |
| `runtime_info.input.llm_api.*` | Point Curator at the right model endpoint and Claude Code proxy mode. |
| `runtime_info.input.languages.<lang>` | Enable languages and tune timeout, concurrency, and task caps. |
| `runtime_info.input.github_token` | Usually leave empty and supply tokens through env or token files. |

## Field guide

| Field | Meaning | User action |
| --- | --- | --- |
| `meta_info.name`, `label`, `description`, `parent` | Curator identity and parent block. | Do not edit for normal runs. |
| `meta_info.dependencies.from` | Curator has no upstream task source. | Do not edit. |
| `meta_info.dependencies.to.merged_tasks_dir` | Wires curated tasks to Tracer when Tracer uses a local task source. | Do not edit unless rewiring pipeline outputs. |
| `meta_info.repos.swegen` | Pinned task-generation repository. | Do not edit unless intentionally updating implementation code. |
| `meta_info.environment.*` | Python environment and dependency metadata for `swegen`. | Read during setup; normally do not edit. |
| `meta_info.resources.*` | Host where Curator runs. | Keep local unless moving work to a remote node. |
| `runtime_info.input.pr_collection.enabled` | Whether PR collection is active. | Disable only if using already collected inputs. |
| `runtime_info.input.pr_collection.languages` | Languages to collect from GitHub. | Edit to narrow or expand task sources. |
| `runtime_info.input.pr_collection.repo_num` | Target number of qualifying repositories per language. | Lower for smoke runs, raise for data production. |
| `runtime_info.input.pr_collection.max_prs_per_repo` | Maximum candidate PRs per repository. | Tune for scale and cost. |
| `runtime_info.input.pr_collection.output_dir` | Where collected PR metadata is written. | Usually keep default. |
| `runtime_info.input.pr_collection.token_limit` | First N combined file/env tokens used during collection. | Tune only when collection is too broad or too expensive. |
| `runtime_info.input.pr_collection.filters.*` | Repository and PR quality filters. | Tune to control difficulty, recency, size, and quality. |
| `runtime_info.input.llm_api.api_key` | LLM API key marker. | Replace via setup/env; do not commit real keys. |
| `runtime_info.input.llm_api.api_base_url` | LLM API endpoint marker. | Fill with the endpoint used for Curator models. |
| `runtime_info.input.llm_api.pr_model` | Model for PR analysis. | Change when using a different PR filtering model. |
| `runtime_info.input.llm_api.task_model` | Model for task generation. | Change when using a different task-writing model. |
| `runtime_info.input.llm_api.cc_provider_mode` | Claude Code provider mode. | Keep aligned with your proxy/native setup. |
| `runtime_info.input.llm_api.anthropic_base_url` | Anthropic-compatible proxy endpoint. | Edit when your local proxy port changes. |
| `runtime_info.input.llm_api.cc_proxy_port` | Local Claude Code proxy port. | Edit only when the proxy uses another port. |
| `runtime_info.input.github_token` | Fallback GitHub token field. | Prefer env variables or `gh_token.txt`; keep tracked config empty. |
| `runtime_info.input.languages.<lang>.enabled` | Whether to generate tasks for a language. | Toggle per run. |
| `runtime_info.input.languages.<lang>.params.timeout` | End-to-end generation timeout. | Raise for slow ecosystems. |
| `runtime_info.input.languages.<lang>.params.cc_timeout` | Claude Code task-generation timeout. | Raise when generation times out. |
| `runtime_info.input.languages.<lang>.params.n_concurrent` | Per-language concurrency. | Tune for machine capacity and API limits. |
| `runtime_info.input.languages.<lang>.params.max_verified_tasks` | Verified task cap per language. | Use small values for smoke runs. |
| `runtime_info.output.swe_tasks_dir` | Per-language verified task output. | Read downstream; usually do not edit. |
| `runtime_info.output.merged_tasks_dir` | Flattened verified task output for Tracer. | Usually keep default. |
| `runtime_info.output.logs` | Per-language generation logs. | Use for debugging. |
