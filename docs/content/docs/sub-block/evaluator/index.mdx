---
title: evaluator
description: Measure checkpoints and agents on coding benchmarks
---

`evaluator` is the benchmark-measurement stage. It runs registered coding benchmarks through Harbor against a configurable upstream agent or model endpoint, then stores per-task results, trajectories, and reports for analysis.

## At a glance

- **Inputs**: `llm_api`, `litellm_proxy`, `task_source`, `harbor_job`, and `agent`. The benchmark source is selected from Harbor's registry.
- **Output**: `eval_results_dir` — Harbor job directories with per-task evaluation outputs and LiteLLM trajectory logs.
- **Runs**: Remote or local depending on `meta_info.resources.ip`. Long-running for full benchmark suites.

## How to run

```text
/evaluator:setup        # clone/update Harbor and prepare environments
/evaluator:check        # preflight: benchmark registry, model API, envs, resources
/evaluator:run          # launch benchmark evaluation
/evaluator:dashboard    # inspect results, reports, and trajectory logs
```
